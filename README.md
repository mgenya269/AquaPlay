# 🌊 AquaPlay

> Мини-игры о воде, гидрологии и экологии.

## 🎮 Игры

- 🌊 **Водный Баланс** — управляй шлюзом плотины

## 🛠 Технологии

- HTML5 / CSS3 / Vanilla JS
- Capacitor (Android APK)
- GitHub Actions (автосборка APK)

## 📦 Сборка APK

1. Зайди во вкладку **Actions**
2. Дождись workflow **Build Android APK**
3. Скачай APK из раздела **Artifacts**
